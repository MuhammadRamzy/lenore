LENORE BRAND KIT · Version 1.0 · October 2026
Lenore Trading LLP · Refined Bathroom Living

Start with Lenore-Brand-Guidelines.pdf. It explains how to use everything here.

01-Logo
  Five layouts × five colourways, named lenore-{layout}-{colourway}:
    layout     horizontal (primary) · stacked · mark · wordmark · name
    colourway  full-colour (light backgrounds) · reversed (dark backgrounds)
               bronze · black · white (one colour)
  SVG/  master vector files, for the web, apps and designers
  PDF/  vector files, for printers and sign makers
  PNG/  transparent images, for Word, PowerPoint, WhatsApp and social media
        name.png (1200 px), name@2x.png (2400 px), name@4x.png (4800 px)
        Mark: 1024, 2048 and 4096 px high

02-App-Icons
  favicon.ico (16/32/48), favicon.svg, app icons (180–1024 px) on
  Stone, White, Ink, Bronze and Workspace Slate, a maskable icon, and a
  circular profile picture (1080 px) for WhatsApp and social media.

03-Colour
  lenore-colours.ase   swatches for Adobe Illustrator, Photoshop, InDesign
  lenore-colours.css   CSS custom properties for the web
  lenore-colours.json  HEX, RGB, CMYK, usage and contrast for each colour
  contrast.txt         WCAG contrast of every colour on White, Stone and Ink
  CMYK values are conversions from screen colour: always proof on paper.

04-Typography
  Manrope (variable, weights 200–800, plus web WOFF2 400–700) and
  Noto Sans Malayalam. Both are free under the SIL Open Font License
  (OFL.txt in each folder). Install the TTF files to use the templates.

05-Templates
  business-card     90 × 55 mm, 3 mm bleed (PDF to print, HTML to edit, previews)
  letterhead        A4 (PDF, HTML)
  shelf-label       75 × 50 mm price label (PDF, HTML)
  social-post       1080 × 1350 post template (PNG, HTML)
  story             1080 × 1920 WhatsApp status / story (PNG, HTML)
  link-preview      1200 × 630 image for shared website links (PNG)
  signboard-concept 4:1 fascia concept for briefing a sign maker (PNG, HTML)
  email-signature   HTML signature (host the logo PNG first; see the file)
  Edit the HTML templates in any browser-based editor or hand them to a
  designer; text placeholders such as “Your Name” must be replaced.

About the logo artwork
  The mark was redrawn as clean vector artwork from the logo used in the
  Lenore billing app. If the original designer's artwork becomes
  available, compare it with these masters before replacing them.
