# Lenore brand

- [Brand guidelines (PDF)](Lenore-Brand-Guidelines.pdf): essence, voice, logo rules, colour, typography, imagery, interface and applications.
- `logo/`: master SVG logos (horizontal, stacked, mark, wordmark, name × full colour, reversed, bronze, black, white) and `favicon.svg`.
- `colour/`: palette as CSS, JSON and Adobe ASE swatches, with WCAG contrast.

The full brand kit (PNG and PDF logo exports, app icons, fonts with licences and templates) is distributed as `Lenore-Brand-Kit.zip`; see `KIT-README.txt` for its contents. The mark is vector artwork redrawn from the Lenore billing logo; compare it with the original designer's artwork if that is supplied.
